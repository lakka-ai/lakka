# M10 gate: routing accuracy

Status: passed. Both classifiers are gated in the image job, the description fallback
and the blend are never worse than examples alone, and every CI job passes on amd64 and arm64
in GitHub Actions. amd64 was first measured on x86_64 cloud hosts outside CI (ADR 0124); the
image job on GitHub's amd64 runner confirms it (amd64 in GitHub Actions, below).

Gate (docs/roadmap.md): the seven exit criteria below. The work is ADR 0122, ADR 0123, ADR 0124
and ADR 0125. Accuracy is gated in the image job, and the release workflow checks the latency of
the images it pushes.

### amd64

Measured on x86_64 cloud hosts (Intel Xeon, 4 vCPU, AVX2), with the
image's own Node and the same commands under `--network none --cpus 2 --memory 4g`, from the
source tree rather than a built image (ADR 0124, amd64, says why).

- Accuracy within one standard deviation of arm64 for both models, with examples and with
  descriptions; the fallback and the blend never worse.
- `embed-bench` at two threads: MiniLM 52 to 55 ms, mpnet 133 to 148 ms. mpnet's 200 ms budget
  (ADR 0123) was set from these.
- MiniLM's amd64 reference vector is written on amd64, since one written on arm64 failed there
  (cosine 0.9928 against 0.995). It passes at 1.0, as does mpnet's.

## Known gaps

- **Different x86 CPUs choose different INT8 kernels**, so another amd64 host can give slightly
  different figures from GitHub's runner; the reference vectors and budgets are checked there.
- **mpnet is the one place the 100 ms classification limit does not hold.** It is held to 200 ms,
  so a regression that stays under that is not caught (ADR 0123).
- **mpnet with same-language German examples** is at 80.0% (79.98% in ADR 0123), at AC 11's 80%
  with no margin; its gate in the other languages is 78% (ADR 0123).
