# M2 gate: provider gateway

Status: passed. The checks below run in CI on every change; this page records what
they show and where.

Gate (docs/roadmap.md): cost accuracy. Exit criteria:

- a request routed to any configured provider returns a correct cost record
- killing a provider mid-request triggers the documented failover behaviour
- cost figures match the provider's own reported usage within a small margin

Watch out for: the streaming commitment window has to be proven here, not discovered in M5.

## Exit criteria

| Criterion                                                                                         | Evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Where it runs                            |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| A correct cost record from any configured provider (BG-8)                                         | `apps/api/test/m2-exit.integration.test.ts` sends one request through `dispatch` for each provider kind, over real HTTP to a fake provider speaking that provider's protocol: OpenAI-compatible chat completions, Anthropic messages, OpenAI Responses and Google Gemini. Each usage row names the model, provider and credential used, and holds every token class and the cost. The costs match hand calculations: 38, 351, 380 and 740 micro-USD.                                                                                                                                                                                                                      | CI `integration`, Postgres 16 and 18     |
| Killing a provider mid-request triggers the documented failover (invariant 6, ADR 0025, ADR 0040) | `apps/api/test/dispatch.integration.test.ts` covers both sides of the window. A provider that drops the connection before its first chunk is retried, and the client gets a clean stream. A provider that drops after two chunks gives the client an interruption error, is never failed over (the fallback gets no request), and leaves a usage record for the partial output. The same file covers 503s, rate limits, stalls, idle streams, client aborts before and after commit, and terminal errors. Disabling any one of four guards (terminal errors, billing of abandoned attempts, recording of pre-commit aborts, the failover family scope) makes a test fail. | CI `integration`                         |
| Cost matches provider-reported usage within a small margin                                        | Recorded token counts equal the provider's reported counts exactly, for each protocol's own way of reporting cached and reasoning tokens (`packages/core/test/cost-fixtures.test.ts`, `providers.test.ts`). Cost is those counts times the catalogue prices, rounded up once per attempt, so it is at most 1 micro-USD above the exact figure. Checked by hand against published prices: Claude Sonnet 4.5 with cache reads and writes, 1116 micro-USD; GPT-5 mini with cached and reasoning tokens, 155; Gemini 2.5 Flash with thinking tokens, 355.                                                                                                                     | CI `typecheck, lint, format, unit tests` |

The comparison is against each provider's wire format, parsed by the real SDK provider
packages, not against a live provider bill: live checks were declined (M2 plan, D10).
Recorded cost can exceed a bill, through rounding, estimates when usage is missing, and
abandoned attempts. It never falls below one, except for the prices ADR 0037 lists as not
modelled.

## Known limits and open items

- **To revisit with real data:** a client that leaves a reasoning model early is charged its output limit, because hidden reasoning cannot be measured (ADR 0040). The context-window check uses a byte-based estimate, and a provider's own refusal triggers failover when it is too low.
- **Not modelled prices** (ADR 0037): OpenAI priority, flex and batch; regional uplifts; Anthropic one-hour cache writes.
- **Optional:** a manually triggered live-provider check, if provider keys become available (D10).
