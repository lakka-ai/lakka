# M5 gate: surfaces

Status: passed, on amd64 and arm64 in GitHub Actions. The checks below run in these CI jobs:

- `check`;
- `integration` on Postgres 16 and on Postgres 18;
- `image`;
- `stack`, with the acceptance suite from first-run setup, both SDKs, Open WebUI and LibreChat,
  and the shutdown check.

The "Where it runs" column names the CI job that carries each check.

Gate (docs/roadmap.md): exit criteria are acceptance criteria 4 to 6 and 14 to 15. What matters
most: below the transport layer, a chat request and an API request can't be told apart.

## Known limits and open items

- **Deferred:**
  - sharing conversations (CH-6, a SHOULD; Q4);
  - clearing a conversation's route by hand (picking a model in chat overrides it).
- **Known limits:**
  - Auto's file support does not know a conversation's earlier routing decision, so a file can still be refused. The refusal is a clear sentence, and the message is kept (ADR 0062).
  - Files live in the main database, so backups grow with them.
  - What is left to spend counts settled spend, and shows a member the headroom, not the limit, of workspace and instance caps (ADR 0061).
  - Only the process holding a stream can end it, which fits the single-instance deployment (ADR 0063).
  - The pinned client versions are deliberate updates. Open WebUI's and LibreChat's APIs change between versions, so the checks may need adjusting on upgrade (ADR 0064).
