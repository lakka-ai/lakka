Routing

Routing reads each message and sends it to the model that suits it. It is optional. With it off, everyone gets the default model unless they pick one.

Settings

People see Auto in the model picker. Each reply says which route matched and how sure routing was.
Default modelUsed when no route matches, and for everything when routing is off.
Pinned modelIf set, every request uses this model. Routes and personal choices are ignored.
