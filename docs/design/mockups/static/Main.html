2. Meaning

Money states

The meter always shows what is left, not what is used. Low starts at 20 percent left, or at the first alert threshold if an admin set one higher. Custom tokens: --lk-money-healthy, --lk-money-low, --lk-money-exhausted, each with a -soft pair.

3. Type

Atkinson Hyperlegible Next and Newsreader

Atkinson Hyperlegible Next for the interface, drawn so similar letters and figures stay apart. Newsreader for page titles and answer sentences only. Atkinson Hyperlegible Mono for model names, keys and commands. All three bundled, system stack as fallback. Numbers use tabular figures everywhere money or time lines up.
