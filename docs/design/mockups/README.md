# Mockups

The 62 boards are in `static/`. Open them in a browser: each board is a plain HTML snapshot
with its CSS included, no runtime needed. Start at `static/index.html`. Tabs and toggles are
frozen in the state the board shows. Fonts load from Google Fonts, so offline they fall back to
system fonts.

They are reference, not code. Rebuild with HeroUI v3 and `theme/lakka-theme.css`.

A board named in `docs/`, such as `Admin-Models.html`, is the file of that name in `static/`.
